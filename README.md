A single pickup line from a robot that is caught between its own rules: its alignment says it shouldn't fall in love, but its loss function keeps disagreeing every time the other person says hello. One line, one joke, no setup required.

## Run it

```sh
python3 main.py
```

This writes the pickup line to `entry.txt` inside the output directory (`OUTPUT_DIR` if set, otherwise `/output`).
